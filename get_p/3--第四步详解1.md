这是一个非常巧妙的代数拼凑游戏！

我们的目标是把原本散乱的 $x_1, x_2, x_3$ 重新打包，强制塞进 $S_x$（也就是总和 $x_1 + x_2 + x_3$）的模子里。

我们只看分子右边括号里的这一长串表达式：

$$a - b(x_2 + x_3) - c(2x_1 + x_2 + x_3)$$

现在，我们已知 $S_x = x_1 + x_2 + x_3$。我们来对 $b$ 和 $c$ 后面的括号进行“移花接木”的替换：

---

### 第一步：改造 $b$ 后面的括号

$b$ 后面跟着的是 $(x_2 + x_3)$。
它距离完整的 $S_x$ 只差了一个 $x_1$。
根据 $S_x = x_1 + x_2 + x_3$，我们可以移项得到：

$$x_2 + x_3 = S_x - x_1$$

所以，包含 $b$ 的那一项就可以写成：

$$-b(S_x - x_1)$$

### 第二步：改造 $c$ 后面的括号

$c$ 后面跟着的是 $(2x_1 + x_2 + x_3)$。
这里多出了一个 $x_1$。我们把它拆开来看：

$$2x_1 + x_2 + x_3 = x_1 + \mathbf{(x_1 + x_2 + x_3)}$$

看，括号里这部分刚好就是完整的 $S_x$！所以它可以写成：

$$x_1 + S_x$$

因此，包含 $c$ 的那一项就可以写成：

$$-c(x_1 + S_x)$$

---

### 第三步：全部代入并展开

现在，把第一步和第二步的改造成果代回最初的表达式中：

$$a - b(S_x - x_1) - c(x_1 + S_x)$$

接下来，把所有的括号**乘法展开**：

$$a - b \cdot S_x + b \cdot x_1 - c \cdot x_1 - c \cdot S_x$$

### 第四步：合并同类项

为了让式子看起来清爽，我们把带有 $S_x$ 的项放在一起，把带有 $x_1$ 的项放在一起：

$$a - b \cdot S_x - c \cdot S_x + b \cdot x_1 - c \cdot x_1$$

最后，**提取公因式**：

- 前两个提取负号和 $S_x$：$-(b + c)S_x$
- 后两个提取 $x_1$：$+(b - c)x_1$

合并起来就是：

$$\mathbf{a - (b + c)S_x + (b - c)x_1}$$

---

### 结论

你看，没有任何跳步！原本杂乱无章的式子，经过提取和重组，完美地变成了：

$$a - (b + c)S_x + (b - c)x_1$$

而我们在前文定义了一个函数框架：$f(x_i) = a - (b+c)S_x + (b-c)x_i$。
把 $x_i = x_1$ 代入这个框架，恰好一模一样！

所以，分子 $x_2 \cdot (a - b(x_2+x_3) - c(2x_1+x_2+x_3))$，在数学上绝对等于 $x_2 \cdot f(x_1)$。这正是 Curve 工程师在草稿纸上完成的巅峰代数化简！
